# Project Codex Skills

Use these skills when working in this repository:

- `project-java-rules`: Project-level Java development, design document, comment, and change-process rules. Use by default for Java code changes, design docs, comments, compatibility-sensitive changes, and implementation planning.

- `architecture-rfc`: Use for design documents, architecture proposals, solution review drafts, migration plans, and implementation constraint documents.
- `java-infra-review`: Use for Java infrastructure code reviews, especially code touching RocksDB, Netty, Raft, networking, SSH/HTTP, concurrency, transactions, timeouts, logging, JDK8 compatibility, or Gradle.

Prefer Chinese for project explanations, source comments, RFC/review documents, and commit messages unless the user asks for another language. Keep all files UTF-8. Design documents must also maintain an English translation copy, such as `xxx-design.md` and `xxx-design.en.md`.
